# Code of Conduct (Alpha)
Participation in UAGF spaces requires respectful, harassment-free collaboration. Be professional; critique
content and evidence, never people; no discrimination, doxxing, or personal attacks. Reports go to the
maintainer contact in SECURITY.md. Enforcement decisions rest with the SATHIRA Institution maintainers.
