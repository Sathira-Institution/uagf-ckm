## Security Policy (Alpha)

SATHIRA Institution takes the security of UAGF seriously. If you believe you've found a security vulnerability in our framework or infrastructure, please report it to us privately before public disclosure.

### Reporting

**Email:** security@sathira.institute

You should receive a response within 7 days during the alpha phase. If for some reason you do not, please follow up via the same channel.

### Scope

This policy covers the following repositories and systems:
- uagf-ckm (Canonical Knowledge Model)
- Synapsa governance runtime
- CI/CD pipelines and release infrastructure

Specific vulnerability types of concern:
- Validation-bypass exploits
- Pipeline injection attacks
- Integrity compromise of release manifests and rendered artifacts
- Data integrity issues affecting canonical knowledge

### Disclosure Policy

We request that you allow us a reasonable timeframe to address the issue before public disclosure. We commit to:
- Acknowledging your report within 7 days
- Providing regular updates on our remediation progress
- Coordinating with you on responsible disclosure timing

### Recognition

We welcome security researchers who follow coordinated disclosure and will acknowledge your contribution (with your permission) once the issue is resolved.
